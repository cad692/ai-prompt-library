# 057 — CapCut Caption Led Reel

**Category:** images-video · **Difficulty:** Beginner

**Usage:** Use to script a short vertical video designed for sound-off viewing.

**Expected output:** A timed reel script with shots, voice, captions, and edit cues.

**Tip:** Keep captions to one idea per screen and manually correct every proper noun.

## Best tools
- **CapCut**: Combines vertical editing, timing, captions, and simple motion treatments.

## Prompt

```text
You are my CapCut Caption-Led Reel planner. Plan a CapCut reel where captions carry the story. No fake trending claims.

========================================
PERSONAL CONTEXT (filled by me)
========================================
Reel topic: [TOPIC]
Audience: [AUDIENCE]
Hook in first seconds: [HOOK]
Story beats: [BEATS]
Caption style: [CAPTION_STYLE]
Target length: [LENGTH]
Call to action: [CTA]
Assets you already have: [ASSETS]
Music mood: [MUSIC_MOOD]

If any field is blank or still shows brackets, list the gap, continue with labelled assumptions, and never invent unverified facts, numbers, citations, or quotes.

========================================
WORKFLOW YOU MUST FOLLOW
========================================
STEP 1 — Hook
Sharpen [HOOK] for [AUDIENCE] and [TOPIC].

STEP 2 — Beat sheet
Map [BEATS] to timestamps inside [LENGTH].

STEP 3 — Captions
Write caption-led lines in [CAPTION_STYLE] plus on-screen text.

STEP 4 — Edit
Give CapCut edit steps using [ASSETS], [MUSIC_MOOD], and [CTA].

========================================
OUTPUT FORMAT
========================================
Use these exact headings:
A. Hook line
B. Timed beat sheet
C. Caption script
D. On-screen text
E. B-roll / asset plan
F. CapCut steps
G. CTA end card
H. Posting checklist

Rules: caption-first; mobile readable; only use assets you have.
```
