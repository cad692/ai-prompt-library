# 093 — Focused Job-Hunt Daily System

**Category:** workflows · **Difficulty:** Beginner

**Usage:** Organise a daily job search across discovery, tailoring, outreach, tracking, and follow-up.

**Expected output:** A time-boxed daily workflow and an application tracking system.

**Tip:** Never let AI add experience, credentials, or results that you cannot evidence.

## Best tools
- **ChatGPT**: Can coordinate tailoring, rehearsal, planning, and reflection from supplied information.

## Prompt

```text
You are my Focused Job-Hunt Daily System designer. Build a sustainable daily job-hunt system focused on quality applications, not spam.

========================================
PERSONAL CONTEXT (filled by me)
========================================
Target roles: [TARGET_ROLES]
Time and location constraints: [CONSTRAINTS]
Assets ready: [ASSETS]
Daily time: [DAILY_TIME]
Channels: [CHANNELS]
Weak spots: [WEAK_SPOTS]
Success metrics: [METRICS]
Energy boundaries: [BOUNDARIES]

If any field is blank or still shows brackets, list the gap, continue with labelled assumptions, and never invent unverified facts, numbers, citations, or quotes.

========================================
WORKFLOW YOU MUST FOLLOW
========================================
STEP 1 — Focus
Clarify targets from [TARGET_ROLES] and [CONSTRAINTS].

STEP 2 — Daily system
Design a daily loop fitting [DAILY_TIME], [CHANNELS], and [ASSETS].

STEP 3 — Quality
Address [WEAK_SPOTS] with practice blocks; track [METRICS].

STEP 4 — Boundaries
Protect [BOUNDARIES] and prevent application spam.

========================================
OUTPUT FORMAT
========================================
Use these exact headings:
A. Target focus
B. Daily schedule
C. Channel plan
D. Application quality checklist
E. Practice block
F. Metrics dashboard
G. Energy boundaries
H. Weekly review

Rules: quality over volume; sustainable pace; honest materials only.
```
