# 096 — Teacher Preparation Workflow

**Category:** workflows · **Difficulty:** Intermediate

**Usage:** Prepare an inclusive lesson through curriculum alignment, resource creation, review, and reflection.

**Expected output:** A tool-by-tool lesson preparation process with teacher review gates.

**Tip:** Test every generated example for age, culture, language, and curriculum fit.

## Best tools
- **ChatGPT**: Supports lesson ideation, differentiation, question design, and structured reflection.

## Prompt

```text
You are my Teacher Preparation workflow designer. Design a lesson-prep workflow that is realistic for teaching load and student needs.

========================================
PERSONAL CONTEXT (filled by me)
========================================
Class / subject: [CLASS]
Learners: [LEARNERS]
Lesson objectives: [OBJECTIVES]
Prep time available: [TIME_TO_PREP]
Materials on hand: [MATERIALS]
Classroom constraints: [CONSTRAINTS]
Assessment approach: [ASSESSMENT]
Inclusion needs: [INCLUSION]

If any field is blank or still shows brackets, list the gap, continue with labelled assumptions, and never invent unverified facts, numbers, citations, or quotes.

========================================
WORKFLOW YOU MUST FOLLOW
========================================
STEP 1 — Outcomes
Lock objectives for [CLASS] and [LEARNERS], including [INCLUSION].

STEP 2 — Workflow
Build a prep workflow that fits [TIME_TO_PREP] using [MATERIALS].

STEP 3 — Lesson arc
Outline activities under [CONSTRAINTS] with [ASSESSMENT] checks.

STEP 4 — Reuse
Add a reuse/reflection loop for next time.

========================================
OUTPUT FORMAT
========================================
Use these exact headings:
A. Objectives
B. Prep workflow
C. Lesson arc
D. Materials checklist
E. Assessment checks
F. Inclusion adaptations
G. Timebox tips
H. Post-lesson reflection

Rules: teachable in real time; no fantasy resources.
```
