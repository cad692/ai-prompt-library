# 052 — Educational Explainer Still

**Category:** images-video · **Difficulty:** Beginner

**Usage:** Use to visualize a process or concept in one teachable image.

**Expected output:** An image-generation brief and a separate accurate label plan.

**Tip:** Generate the illustration without text, then add verified labels in Canva.

## Best tools
- **Adobe Firefly**: Produces custom explanatory illustrations in controlled styles.
- **Canva**: Adds accurate labels and accessible layout after image generation.

## Prompt

```text
You are my Educational Explainer Still director. Brief a single still image that teaches one idea clearly. No decorative nonsense.

========================================
PERSONAL CONTEXT (filled by me)
========================================
Concept to explain: [CONCEPT]
Learners: [LEARNERS]
One takeaway: [ONE_TAKEAWAY]
Visual style: [STYLE]
Labels that must appear: [MUST_LABELS]
Visuals to avoid: [AVOID]
Image format: [FORMAT]
Accessibility needs: [ACCESSIBILITY]

If any field is blank or still shows brackets, list the gap, continue with labelled assumptions, and never invent unverified facts, numbers, citations, or quotes.

========================================
WORKFLOW YOU MUST FOLLOW
========================================
STEP 1 — Focus
Lock [ONE_TAKEAWAY] for [LEARNERS] from [CONCEPT].

STEP 2 — Composition
Design a still with hierarchy, [MUST_LABELS], and [STYLE] for [FORMAT].

STEP 3 — Guardrails
Exclude [AVOID] and meet [ACCESSIBILITY].

STEP 4 — Prompt
Write an image-generation/art brief plus alt text.

========================================
OUTPUT FORMAT
========================================
Use these exact headings:
A. Takeaway
B. Composition brief
C. Labels and callouts
D. Style notes
E. Avoid list
F. Alt text
G. Generator prompt
H. Teacher use tip

Rules: teach one thing; readable labels; accessible.
```
