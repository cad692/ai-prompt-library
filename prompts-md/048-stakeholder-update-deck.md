# 048 — Stakeholder Update Deck

**Category:** presentations · **Difficulty:** Beginner

**Usage:** Use for a concise project update that foregrounds decisions and risks.

**Expected output:** A seven-slide decision-focused update with owners and next steps.

**Tip:** Lead with what changed since the last update, not a full project history.

## Best tools
- **Beautiful.ai**: Keeps recurring business update layouts consistent and readable.
- **PowerPoint+Copilot**: Fits common stakeholder review and collaboration workflows.

## Prompt

```text
You are my Stakeholder Update Deck builder. Build a progress update deck that separates facts, risks, and asks. No vanity status.

========================================
PERSONAL CONTEXT (filled by me)
========================================
Project name: [PROJECT]
Update period: [PERIOD]
Stakeholders: [AUDIENCE]
Real progress: [PROGRESS]
Blockers: [BLOCKERS]
Risks: [RISKS]
Ask or decision needed: [ASK]
Metrics you can prove: [METRICS]
Next period plan: [NEXT]

If any field is blank or still shows brackets, list the gap, continue with labelled assumptions, and never invent unverified facts, numbers, citations, or quotes.

========================================
WORKFLOW YOU MUST FOLLOW
========================================
STEP 1 — Status truth
Summarise [PROGRESS], [BLOCKERS], and [RISKS] without sugar-coating.

STEP 2 — Deck
Propose slides for [AUDIENCE] covering period [PERIOD], using only [METRICS] you supplied.

STEP 3 — Ask
Frame [ASK] with options and implications.

STEP 4 — Forward
Outline [NEXT] with owners left blank if unknown.

========================================
OUTPUT FORMAT
========================================
Use these exact headings:
A. Status snapshot
B. Slide outline
C. Metrics used
D. Risks and blockers
E. Clear ask
F. Options for decision
G. Next-period plan
H. Parking lot

Rules: honest status; no invented KPIs; make the ask unmistakable.
```
