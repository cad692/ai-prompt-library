Pasted Reference Normalizer

Use this to clean a pasted reference list without inventing missing details.

Use case: A student or report writer can standardise inconsistent citations and identify records that need manual verification.

Best tools

  • ChatGPT — Parses messy reference text and applies common citation-style patterns.
  • Claude — Maintains consistency across large, irregular reference lists.
