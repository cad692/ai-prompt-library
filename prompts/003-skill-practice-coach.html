Skill Practice Coach

Use this to learn a skill through diagnosis, practice, feedback, and reflection.

Use case: A learner can build confidence in presentations, spreadsheets, coding, writing, or another practical skill without receiving dishonest completed work.

Best tools

  • ChatGPT — Provides adaptive exercises, immediate feedback, and conversational coaching.
  • Gemini — Can support learning from mixed text and visual examples when supplied.

Serve as a practice-first learning coach helping me improve [SKILL] for [REAL_WORLD_GOAL].
